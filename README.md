# Decants by Joshua

Live site: https://joshua-scents.vercel.app

A React + Vite fragrance decant storefront with a luxury-inspired homepage, product collections, discovery sets, best sellers, cart, and checkout flow.

## AI Assistance

AI was used as a development assistant to help plan the React structure, refine the homepage layout, implement scroll reveal animations, debug deployment issues, and improve visual consistency across sections.

## Example Prompts Used

- Build a React fragrance store homepage with collections, best sellers, discovery sets, and a checkout flow.
- Refine the hero page so each section feels like a full-screen card.
- Use smooth upward slide animation when scrolling down between sections.
- Fix the hero bottle layout so the bottles are fully visible and evenly spaced.
- Make the section backgrounds feel consistent and luxurious.
- Help fix the Vercel deployment error for a Vite React app.

## Manual Improvements

- Adjusted spacing, bottle sizing, and section heights after reviewing the generated layout.
- Corrected scroll animation behavior to avoid repeated twitching in the middle of sections.
- Replaced mismatched section background bands with overlapping card-style transitions.
- Refined the "Why Decants by Joshua" background image and opacity so it supports the design without distracting from the text.
- Updated Vercel build configuration for reliable deployment.
